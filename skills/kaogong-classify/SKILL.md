# 照片分类与判对错（kaogong-classify）

收到一批**混合**照片（讲义页 / 题目页 / 标准答案页）时走这条流程。
前置：OCR 与校准（见 `kaogong-ingest`）。这里管的是**分派**。

## 一、先跑两条流水线

```bash
# 黑字层 → markdown（题干/正文） + 红笔层（手写批注）
~/.pi/bin/kaogong-ocr.sh --source "<批次名>" --module <科目/模块> --with-marks 图1.jpg 图2.jpg ...
```

产出：

```text
考公/_raw/<模块>/<批次名>-pNNN.md          黑字层（机器产出，未校对）
考公/_raw/<模块>/marks/...-pNNN-marks.jpg  红笔层图 ← 判对错与推错因的依据
考公/_raw/<模块>/marks/...-pNNN-marks.txt  红笔层文字（手写识别很弱，仅作参考）
```

**红笔层的字主要靠你自己看图读，不要信 marks.txt** —— Vision 认印刷体很准，
认手写体基本不行（实测一行批注只读出个符号）。图是给人看的。

## 二、逐页分类

```bash
python3 ~/code/kaogong/pipeline/classify.py <页面.md> --json
```

返回 `handout` / `questions` / `answers` / `unknown`：

| 类型 | 去处 |
| --- | --- |
| handout 讲义页 | 走 `split.py` → 骨架 + 考点卡片 |
| questions 题目页 | 逐题判对错（下一步） |
| answers 答案页 | 解析成标准答案表，给判对错用 |
| unknown | **列出来问用户**，不要硬塞进任何一类 |

## 三、判对错（判据按可靠性排序）

```bash
python3 ~/code/kaogong/pipeline/classify.py 题目页.md --key 答案页.md --student "1:B,2:D,5:ABD"
```

`--student` 里的作答**由你读红笔层填进去**。判据优先级：

```text
1  标准答案页比对      最硬：classify.py 自动比
2  红笔批改痕迹        次硬：叉号/圈掉 → 错；对勾 → 对
3  红笔订正内容        辅助：红笔写的 ≠ 学生写的 → 错
4  都没有              → verdict 留在 unknown，汇总问用户，绝不猜
```

**「绝不猜」是硬规矩。** 猜错的代价：复习了不该复习的、跳过了真正不会的。

## 四、按结果分派

```text
verdict = wrong     → mistake.py new（错题本）
verdict = right     → 丢弃，不落库、不占复习负担
verdict = unknown   → 汇总进汇报，等用户确认后才处理
```

错题入库要带两个字段（缺了这道错题就没价值）：

```bash
python3 ~/code/kaogong/pipeline/mistake.py new \
  --module <模块> --stem "<题干摘要>" --mine B --correct D \
  --confidence 高|中|低 --cause 概念性|程序性|粗心|超纲 \
  --points "<相关考点>" --lecture "<所属小节>" --source "<来源>"
```

**答题信心**从红笔推（写得很确定又划掉 → 高）；**错因**按下一节的判据。

## 五、错因怎么从红笔推

| 红笔写了什么 | 判成 | 依据 |
| --- | --- | --- |
| 纠正定义 / 公式 / 术语，或写原理 | 概念性 | 概念性错误要走「概念转变」 |
| 只改步骤或换个算法，没提概念 | 程序性 | 程序性错误走「题型交错」 |
| 只圈数字 / 单位 / 符号，没写字 | 粗心 | 不进复习队列，单独盯限时正确率 |
| 写「不考」「坑」这类 | 超纲·陷阱 | 归档，低优先 |
| **看不出来** | 不要填 | 列进待确认，问用户 |

## 六、关联（三路都用）

```text
显式   错题里的术语 → 字面匹配已有考点卡（如「另有他因」）
语义   qmd vsearch 语义召回（措辞不一致时只有它能命中）
结构   所属章节/题型 → 同小节的其它考点
         ⚠️ 语义召回只做候选，命中后要复核「真的相关吗」——
            实测纯向量第一名经常是篇不相关的笔记
```

## 七、汇报格式（每次跑完都给）

```text
本批 12 张：
  去重跳过 2 张（同页重拍）
  讲义页 3 张 → 27 个考点
  题目页 6 张 → 48 道题：错 9 / 对 39（丢弃）
  答案页 1 张 → 48 条标准答案
  待确认：3 道（对错判不出）/ 2 道（错因拿不准）
```

## 硬规则

- ❌ 不猜对错、不猜错因 —— 拿不准就列出来问
- ❌ 不把 unknown 页面硬塞进讲义或题目
- ❌ 不信 marks.txt 里的手写识别结果，看图
- ✅ 对的题要真的丢弃（否则复习负担翻倍）
- ✅ 错题必须带 答题信心 + 错因 两个字段
- ✅ 每批跑完报数字（分类结果 / 错题数 / 丢弃数 / 待确认数）
