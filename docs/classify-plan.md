# 错题与知识点的自动分类 · 计划 v0.1

> 2026-09-13 · 你的选择：(b) 红笔批改 + (c) 标准答案页

## 一、输入与产物

**输入**：一批照片（讲义页 / 题目页 / 标准答案页，混着发也行）

**产物**：

```text
知识点   考公/<科目>/<模块>/<讲义>.md     骨架，查阅用
         考公/考点/<考点名>.md            卡片，FSRS 排期
错题     考公/错题/<日期>-<模块>-<摘要>.md 含答题信心 / 错因 / 关联
对的题   （丢弃，不落库、不占复习负担）
```

## 二、流水线（7 步，其中 2 步是新建）

```text
① 分页与去重      已有   批内同页重拍 + 跨次已处理过的，都跳过
② 双层 OCR        已有+新 黑字层（印刷体） + 红笔层（你的批注）
③ 我校准          已有   逐页对着原图核，改错字、记校准记录
④ 页面分类        新建   讲义页 / 题目页 / 答案页
⑤ 逐题判对错      新建   标准答案比对 + 红笔批改痕迹 → 对/错/待定
⑥ 错因识别        新建   从红笔批注推断，拿不准就列出来问你
⑦ 建笔记+关联+排期 已有   错题模板、考点双链、FSRS 队列、三关验证
```

## 三、页面分类规则（第 ④ 步）

```text
讲义页   有标题层级（第X章/一、/（一））、无题号、正文成段
题目页   有题号 + 选项（A. B. C. D. 或 ①②③④ 作选项）
答案页   标题含「答案 / 解析 / 参考答案」，或密集的「题号+字母」表
判不出   单独列出来问你（不猜）
```

## 四、判对错的判据（第 ⑤ 步，按可靠性排序）

```text
1  标准答案页比对    最硬：逐题把学生作答与答案表比
2  红笔批改痕迹      次硬：✗ / 叉 / 圈掉 → 错；✓ → 对
3  红笔订正内容      辅助：红笔写的答案 ≠ 学生作答 → 错
4  都没有            → 标「对错待定」汇总问你，绝不猜
```

## 五、错因识别（第 ⑥ 步）

三类 + 依据（依据哪一条写进笔记，便于你复核）：

```text
概念性     红笔在纠正定义 / 公式 / 术语，或写出原理说明
程序性     红笔只改步骤或换算法，没提概念
粗心       红笔只圈数字 / 单位 / 符号，没有文字说明
超纲·陷阱  红笔写「不考」「坑」这类
拿不准     → 列入待确认，不替你填
```

**依据（文献）**：概念性错误要做「概念转变」（反例打脸 → 重构规则 → 举正例 → 变式验证），
程序性错误进题型交错队列 —— 两类走不同流程，所以错因不能瞎填。

## 六、错题笔记的内容从哪来（第 ⑦ 步）

模板已有五段，各段来源：

```text
① 先自己重做        留空，等你复习时做（这是 Metcalfe 条件一：先察觉到自己错）
② 我当时怎么想的    从你的红笔批注里推（你写下的思路就是「当时怎么想的」）
③ 正确解法          答案页的解析 + 红笔订正
④ 错因归类+下次怎么防 第五节的判定 + 具体到「下次看到 X 要想到 Y」
⑤ 关联              下一节
```

## 七、关联怎么做（三个来源，都会用）

```text
显式   错题里的关键术语 → 字面匹配已有考点卡（如「另有他因」）
语义   qmd 的 notes collection 检索同知识点错题与相近考点
结构   所属章节 / 题型 → 同小节的其它考点
产出   front-matter: 知识点 [[...]] / 同知识点错题 / 所属小节 / 变式训练
```

## 八、排期与复习（已有，按错因分流）

```text
知识性错误   → 进 FSRS 复习队列（初始间隔按考试日反推，当前 12 天）
方法性错误   → 进题型交错队列（同组不排同一天，防记混）
粗心         → 不进复习队列，进「限时正确率」指标单独盯
超纲·陷阱    → 归档，低优先
高信心错误   → 缩短间隔、多轮复测（文献：纠正效果最好，但一周后会复发）
```

## 九、每次跑完给你的汇报格式

```text
本批 12 张照片：
  去重跳过 2 张（同页重拍）
  讲义页 3 张 → 新增 27 个考点
  题目页 6 张 → 48 道题
      错题 9 道（已建卡，关联到 7 个考点）
      对题 39 道（丢弃）
  答案页 1 张 → 解析出 48 条标准答案
  待确认：3 道（对错判不出） / 2 道（错因拿不准）
```

## 十、风险与对策（说在前面）

| 风险 | 对策 |
| --- | --- |
| 手写 OCR 不可靠 | 红笔层不靠 OCR 认字，我自己看图判；OCR 只用来定位 |
| 红笔层会把手指/阴影当红色（皮肤 R>G>B，实测有） | 按色块大小过滤，只留笔画 |
| 答案页格式五花八门 | 先支持「1-5 BCDAB」连续表和「1. B」逐题两种，其它格式列出来问你 |
| 一批太多张 → 我校准时间长 | 建议 ≤20 张/批 |
| 红笔没批改、也没答案页的题 | 标「对错待定」，绝不猜 |

---
**一句话**：照片进来 → 双层 OCR → 去重 → 我校准 → 分类 → 判对错 → 错题建卡并关联考点 → 对的丢弃。
**判对错的优先级：标准答案 > 红笔批改 > 红笔订正 > 待定（绝不猜）。**
