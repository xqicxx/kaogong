# 排期算法对照验证 —— 拿官方 py-fsrs 校对手写实现

> 2026-09-13 · 触发点：同类项目调研时发现官方有维护中的 Python 实现

## 为什么做这件事

我们的 FSRS-4.5 是**手写**的，而验证它的只有我自己写的 selftest —— **那是自证**。
官方 `open-spaced-repetition` 有维护中的实现，可以拿来做**独立**对照：
同一组输入、同一个公式，两边算出来必须一样。不一样的地方，要么是版本差异，要么是 bug。

## 怎么做

装 `fsrs==4.1.2`（4.x 最后一版，19 参数；参数布局与 4.5 同构，可直接喂我们的 17 个参数）。

```bash
python3 -m venv /tmp/fsrcmp/v
/tmp/fsrcmp/v/bin/pip install 'fsrs==4.1.2'
/tmp/fsrcmp/v/bin/python /tmp/fscmp5.py     # 对照脚本
```
